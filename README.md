# ✈️ Travel Agency - Landing Page

Página de aterrizaje semántica desarrollada en **HTML5** para una agencia de viajes ficticia. Este proyecto demuestra el uso correcto de elementos estructurales, listas de navegación, enlaces externos seguros y galerías de imágenes con descripciones integradas.

---

## 🚀 Características

* **Estructura Semántica:** Uso de etiquetas modernas de HTML5 (`<figure>`, `<figcaption>`, `<header>`, etc.).
* **Paquetes de Viaje:** Listas desordenadas con enlaces interactivos dirigidos a recursos externos.
* **Galería de Itinerarios Top:** Imágenes de destinos con leyendas descriptivas para cada tipo de aventura (playa, montaña y ciudad).
* **Enlaces Externos Seguros:** Apertura de pestañas externas optimizada con el atributo `target="_blank"`.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura y marcado semántico)
